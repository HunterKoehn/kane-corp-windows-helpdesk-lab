# Kane Corp. Windows Help Desk Home Lab

I'm building a small Windows-based business environment as a personal home lab to practice IT support, Windows administration, networking, and cybersecurity.

The lab is based around a fictional company called Kane Corp.

## Current Setup

- VMware Workstation Pro
- Windows Server 2025
- Windows 11
- Isolated virtual network

### Server
- Hostname: `KANE-DC01`
- Operating System: Windows Server 2025 Standard Evaluation
- Role: Domain Controller / DNS Server

### Planned Client
- KANE-CL01
- Windows 11

## What I'm Practicing

- Windows Server administration
- Active Directory
- DNS
- Group Policy
- User and group management
- File permissions
- Networking and troubleshooting
- Help desk ticketing
- Basic cybersecurity concepts
